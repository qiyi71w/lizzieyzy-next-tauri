## D01 — Session-only PK batches, opening catalog and intervention

Current capability: [R15 — 批量 PK、开局库、换色和手动干预](../R15_PLAN.md#pk). Historical source: `01-pk-batch.md`.

### Functional input scope

GAME-03::accepted; GAME-05::accepted; T02-I18N-FOUNDATION (validated shared result only); T02-EXPORT-03 (validated actual chart-output result only when batch winrate images are requested; PK queue/catalog/color/intervention and durable completed SGFs proceed independently)

### Behavior and decision contract

Extend explicit PK start and live PK controls to an ordered session-only batch without weakening single-game Match ownership.

Select SGF opening catalog entries in sequential order or deterministic random order whose chosen order is visible and retained for this session.
