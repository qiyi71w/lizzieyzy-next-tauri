## Defaults, persistence, and failure ownership

| Concern | Owner | Frozen / decided contract |
| --- | --- | --- |
| Durable application preferences | `PREF-01` | Native preference file. Missing file loads defaults. Unreadable file is isolated, defaults load, recovery is reported. An explicit setting becomes durable only after an atomic write succeeds; failure preserves the last durable value and reports the error. Java `config.txt` is not imported. |
| Window geometry | `WINDOW-01` | First launch uses the OS/Next default. Persist valid position/size; auto-reset only geometry that is invalid for current displays. Explicit reset changes window geometry only. |
| Workspace proportions | `LAYOUT-01`, `LAYOUT-02`, `LAYOUT-03` | Direct divider manipulation; atomic save after debounce with visible unsaved state on failure; narrow restore of panel sizes and board proportion only. |
| Rail visibility | `LAYOUT-04` | Left and right rails visible by default; independent collapse persists through `PREF-01`. |
| Appearance | `APPEAR-01` | Classic default, High Contrast alternate, persisted through `PREF-01`. System DPI; no app font slider. |
| Educational tips | `GUIDE-01` | Persist dismissals only for **named** Educational Tips; Reset Guidance re-enables those tips. Dirty-state Safety Confirmations are never permanently dismissible. Ticket 21 Defers `GUIDE-01` until a later disposition names a producer whose owner is in a numbered phase. `SET-HINT-AUTOANALYZE` is excluded with abandoned `CAP-04-ANA-08`. `ANA-06` and Ticket 25 notices do not auto-start this item. |
| Current-game replacement | `SGF-07` | Parse/validate before commit. Cancelled or failed Save / Discard / Cancel preserves the complete current game. |
| Session recovery | `APP-04` | Recovers SGF tree, personal comments, `NodePath`, source path, and dirty state after an unclean exit. Never restores engines, analysis jobs, Match Sessions, or provider sessions. Normal-launch restore defaults off. |
| Graceful shutdown | `APP-03` | Dirty game uses Save / Discard / Cancel. Failed or cancelled save aborts exit. Teardown timeout names the stuck resource and offers Retry or contextual Exit anyway. |
| Engine run / jobs | `ENG-02`–`ENG-07`, `ANA-03` | Runs, capability snapshots, and jobs do not persist across application restart. Typed failure; no automatic restart. |
| Match sessions | `GAME-01`, `GAME-05` | Live turn/pause/job/budget state does not persist. Restart never restores a Match Session. |
| Provider / sidecar | `PROV-01`–`PROV-07`, `READ-02` | Preview never mutates the current game. Ongoing sync preserves last-good board on failure; stop leaves an editable game. Timeouts: Yike 10s; Fox/Tencent 20s connect / 25s read. At most three retries after the initial idempotent read; provider writes are never automatically retried. Remote-provider HTTP(S)/WebSocket(S) follows Provider Network Policy; browser-owned traffic, local readboard, and inbound WebBoard are excluded. Only Deferred `PROV-07` may persist a provider-issued user secret, and only in the System Credential Store; proxy secrets never persist in Next. |
| Updates | `REL-03`, `REL-06`–`REL-08` | Discovery failures do not mutate the install. Windows apply backup/rollback plus result journal. macOS/Linux never overwrite in place. OS/system proxy only; no application-specific update proxy. |
| Semantic settings | Owner domain | Lifecycle-affecting engine, analysis, match, provider, and review settings travel with their behavior owners. They are not a catch-all settings phase. `PREF-01` is the durable-preference mechanism, not the semantic owner. |

Java baseline persistence files (`config.txt`, `persist`, `save/save`) remain Java-only evidence. Next persistence is the native preference / profile / cache / app-data contracts named by the mapped items.
