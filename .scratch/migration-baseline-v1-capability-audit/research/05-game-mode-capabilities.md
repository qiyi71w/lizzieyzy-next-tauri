## Method

1. Trace 棋局 / 跑谱贡献 menus, double-menu game cluster, BottomToolbar PK panel, AI Coach toolbar, and `Input` match keys from constructed-and-added controls.
2. Count a Capability only when it is one observable user goal. Count an Entry Point only when a control is constructed **and** added, shown, or registered.
3. Fold PK stop/pause/revise/intervention and generated record facts into the PK session. Fold human pause/resign into the human families. Shared pass, human Stop, contribute occupancy, and start-parameter surfaces stay separate when they are distinct user goals.
4. After the census completed, compare the computed count with reference 8. 8 was not used as a stop condition.
5. Runtime-check is allowed only for a named dynamic-visibility, default, persistence, or failure fact not recoverable from frozen source. Sidecar confirmation live evidence is a `GAME-10` / `READ-02` link, not a Domain 05 Java runtime check.
